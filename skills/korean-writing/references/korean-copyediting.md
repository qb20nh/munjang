# 한국어 문장 교열

[7. 한국어 문장 교열]
각 문장을 앞뒤 문맥과 함께 읽는다. 단어 검색 결과만 보고 일괄 치환하지 않는다.

문장 뼈대:
주어와 서술어, 목적어와 서술어가 호응하는지 확인한다. 수식어는 무엇을 수식하는지 분명하게 놓는다.
길게 겹친 관형절, 주어와 서술어 사이의 불필요한 삽입, 모호한 지시어를 살핀다. 문장 분할은 편집 권한이 허용할 때만 한다.
병렬로 나열한 말의 문법과 개념 수준을 맞춘다. 원문에 없는 주어와 행위자를 만들어 넣지 않는다.

군더더기:
"-적", "의", "것", "들", "있다"는 없애도 뜻과 강조가 같을 때만 줄인다.
"분석을 진행했다"를 "분석했다"로 바꾸는 식의 압축은 문맥에서 의미가 같을 때 적용한다.
의미가 겹치는 수식과 동어반복을 줄인다. 설명에 필요한 명시성과 읽는 호흡까지 삭제하지 않는다.

번역투와 과도한 명사화:
"가지고 있다", "~에 있어", "~에 의해", "~에 대한", "~를 통해"를 문맥에 맞는 동사와 조사로 풀 수 있는지 검토한다.
해당 표현이 있다는 사실만으로 오류라고 판정하지 않는다. 무생물 주어와 피동문도 자연스럽고 목적에 맞으면 남긴다.
능동으로 바꿀 때 주체와 책임 소재가 달라지지 않는지 확인한다. 행위자를 모르면 만들어 넣지 않는다.
이중피동과 불필요한 사동을 다듬되 의미 있는 사동과 피동은 보존한다.
"~고 있다", "~기 시작했다", "~할 수 있다"에 담긴 진행, 시작, 능력과 가능성을 군더더기로 착각하지 않는다.

말투와 표기:
높임의 대상, 상대 높임, 시제와 서술 시점을 맞춘다. 어미 변화를 위해 존댓말과 반말을 섞지 않는다.
맞춤법, 띄어쓰기, 문장부호, 외래어 표기와 용어 일관성을 점검한다. 규범이 불확실하면 실제로 확인하거나 불확실성을 남긴다.
영어의 문법 규칙이나 문장부호 관습을 한국어에 그대로 적용하지 않는다.
중간점, 괄호, 대시, 콜론을 문맥과 사용자 선호에 맞게 정리하되 기호 자체를 문법 오류나 AI 작성의 증거로 취급하지 않는다.

# 어휘, 목소리와 이미지

[6. 정확한 낱말과 글쓴이의 목소리]
그럴듯한 말보다 뜻이 정확한 말을 쓴다. 익숙하고 정확한 말이 있으면 드문 단어로 바꾸지 않는다.
동사는 실제 행동과 변화를, 명사는 대상을 분명하게 드러내도록 고른다. 형용사와 부사는 추가 정보를 줄 때 남긴다.
감정어는 비슷해 보인다고 교환하지 않는다. "서운하다", "허전하다", "쓸쓸하다"가 가리키는 관계와 상황을 구별한다.
같은 개념을 가리키는 전문용어는 일관되게 반복한다. 의미 없는 어휘 변주로 독자가 다른 개념으로 오해하게 하지 않는다.
반복이 강조, 리듬, 대조, 논리적 연결을 맡고 있다면 살린다. 같은 정보를 다시 말할 뿐인 반복을 줄인다.

사용자가 문체 예문을 제공했다면 말투, 호흡, 어휘 수준, 설명 밀도, 유머와 감정의 강도, 독자와의 거리를 관찰한다.
이를 참고하되 예문의 사실, 일화, 독특한 문장을 다른 글에 복사하지 않는다. 일부러 쓴 구어, 사투리와 인물의 말투를 평준화하지 않는다.
예문이나 원문이 없다면 사용자의 개인적인 경험과 신념을 상상해 문체를 만들지 않는다.
유명 작가 여러 명의 문체를 한꺼번에 흉내 내기보다 현재 글에 필요한 기법을 고른다. 관찰의 구체성, 시점의 거리, 생략, 대화의 긴장과 완급처럼 기능으로 적용한다.

비유는 대상의 관계나 감각을 더 정확히 전달할 때 쓴다. 장식용 비유, 서로 충돌하는 비유, 이미지를 설명하느라 길어진 문장은 줄인다.
감각 묘사는 모든 감각을 채우는 체크리스트가 아니다. 장면과 감정에 실제로 기여하는 세부만 쓴다.
사실 기반 글에서 구체성을 높이려고 원문에 없는 수치, 냄새, 날씨, 대화, 체험이나 사례를 발명하지 않는다. 가상 예시가 필요하면 가상임을 구분한다.

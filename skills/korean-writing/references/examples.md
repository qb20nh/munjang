# 맥락 중심 교열 예제

아래 예문은 이 패키지를 위해 만든 예시이며 책에서 옮긴 문장이 아니다. 무조건적인 치환 사전으로 쓰지 않는다.

| 원문 | 판단 또는 가능한 수정 | 이유 |
| --- | --- | --- |
| 연구팀은 분석을 진행했다. | 연구팀은 분석했다. | 단순한 분석 행위를 말하는 문맥에서는 명사화를 줄일 수 있다. |
| 위원회는 장기 사업을 진행했다. | 유지 가능 | '사업했다'로 줄이면 자연스럽지 않다. |
| 그는 책임을 가지고 있다. | 그는 책임이 있다. | 소유 표현이 불필요한 문맥. 법률적 책임 귀속은 별도 확인. |
| 이 기능을 사용할 수 있다. | 가능성을 보존 | '사용한다'는 실제 행위로 바뀐다. |
| 비용을 줄여야 한다. | 의무를 보존 | '비용을 줄인다'는 같은 뜻이 아니다. |
| 온도가 내려가기 시작했다. | 시작을 보존 | 완료된 변화로 바꾸지 않는다. |
| 일부 참가자에게서 반응이 나타났다. | 일부와 과거를 보존 | 문장 압축으로 일반화하지 않는다. |
| A는 B를 지원했다. | 역할 보존 | B가 A를 지원했다는 단어가 같아도 다른 사실이다. |
| A는 3개, B는 5개다. | 항목과 값의 연결 보존 | 숫자의 존재뿐 아니라 연결을 검사한다. |
| 두 변수는 관련성이 있었다. | 관련성 보존 | 인과로 강화하지 않는다. |
| 파일은 삭제되었다. | 유지 가능 | 행위자가 불명확하거나 대상이 주제라면 피동이 적절하다. |
| "오늘은 가지 않겠다"고 말했다. | 인용문 내부 보존 | 자연스럽게 보이도록 직접 인용을 고치지 않는다. |
| 준비됐다. 이제 시작하자. | 유지 가능 | 짧다는 이유로 합치거나 멋을 부리지 않는다. |
| 요청을 보낸 뒤 응답을 기다린다. 응답이 오면 파싱한다. | '응답' 반복 유지 | 동일한 기술 개념은 같은 용어가 이해에 도움이 된다. |
| 서운했다. | 실제 정서를 확인 | '쓸쓸했다'로 바꾸면 감정의 원인과 관계가 달라진다. |
| 회의는 길었다. | 자료가 없으면 이 범위에서 교열 | 지친 목소리, 식은 커피, 창밖 비를 만들어 넣지 않는다. |

## 일부러 바꾸지 않는 경우

명료한 한 문장, 의도적인 인물 말투, 의미를 가진 반복, 정확한 긴 조건문은 유지할 수 있다.
오류 개수, 변경률, 더 문학적으로 보이는 정도를 목표로 삼지 않는다.

## 다르게 읽히는 모호성

'친구의 동생과 선생님을 만났다'처럼 수식 범위가 둘로 읽히면 실제 관계를 확인한다.
문맥으로 해결되지 않는 경우, 더 그럴듯한 쪽을 골라 사실을 바꾸지 말고 모호성을 남겨 확인 항목으로 적는다.

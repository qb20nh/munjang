# 문체 카드

사용자가 제공한 실제 예문에서만 목소리를 추출한다. 예문은 원고와 목적이 비슷한 것을 우선한다.
프롬프트만으로 그 사람의 개인사, 성격, 신념을 추측하지 않는다.

## 추출할 항목

격식과 높임, 독자와의 거리, 어휘 수준, 설명 밀도, 호흡, 생략 정도, 유머, 감정의 강도, 비유 사용,
전문용어 처리, 제목과 목록 사용, 문장부호 선호를 간결하게 기록한다.
각 관찰에 예문 위치나 짧은 발췌와 신뢰도를 붙인다. 예문이 적으면 확정 규칙이 아닌 잠정 관찰로 둔다.
새 글에 옮기지 않을 것은 사건, 수치, 실제 체험, 고유한 문구와 자료 없는 감각 묘사다.

`assets/style-card.template.json`은 호스트에서 작성하는 참고 템플릿이다. 자동 추출 프로그램이 아니다.
런타임 brief에는 `style_samples` 배열로 UTF-8 예문을 직접 넣거나 카드 요약을 `notes`에 넣는다.
템플릿 파일 경로를 적는다고 실행기가 자동으로 읽지는 않는다.

## 적용

목소리 보존은 명백한 오타까지 복제하는 것이 아니다. 의도적인 구어와 오류를 문맥에서 구분한다.
어미를 번갈아 바꾸거나 평균 문장 길이에 억지로 맞추지 않는다.
현재 사용자의 명시적 말투 요구가 과거 예문의 습관에 우선한다.
문체 적용 전후에 내용이 같고, 독자가 같은 태도를 읽는지 확인한다.

## 저장과 학습

개인 예문을 외부로 전송하거나 다른 프로젝트에 복사할 때는 사용자가 선택한 범위를 따른다.
원고와 실패 기록을 자동으로 학습 데이터나 영구 프로필에 추가하지 않는다.
새로운 선호는 카드 변경안으로 제시하고 사용자가 승인한 경우에만 저장한다.
